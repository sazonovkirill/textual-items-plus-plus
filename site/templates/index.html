Calm structure

A place for everything.

New thoughts land in the Inbox. Areas hold the big parts of your life, projects hold the goals inside them, and sections break a project into steps, as in Things 3. The sidebar keeps it all one keystroke away.

o new task s new section np new project M move to

{{ site::shot(src="landing/upcoming.png", class="shot reveal grow", alt="The Upcoming view: tasks and projects grouped by day, tomorrow first, then each day of the week and the rest of October") }}

Plain text

Your list is a text file.

Everything is kept in one .taskpaper file: readable in any editor, easy to sync, diff and back up, and open in TaskPaper too. Dates, flags and pins are ordinary tags, and the app keeps every line it doesn't understand exactly as it was.

{{ site::shot(src="landing/file-view.png", alt="The same project in textual-items++: the flag drawn as a red flag, the section as a heading, the done task hidden and the Later task dimmed") }}

Today

Your day, gathered for you.

Today collects everything that starts or is due today from every project, overdue first, each with the place it lives. Push what can wait to This Evening, mark a project Later, and see the weeks ahead in Upcoming.

gt Today gu Upcoming me this evening

{{ site::shot(src="landing/today.png", class="shot reveal grow", alt="The Today view for the day the screenshot was taken: an overdue flagged review, today's tasks with where each lives, and a reading task under an Evening heading") }}

Keyboard first

Move like vim. Plan like Things.

Keys are mnemonic: g goes somewhere, m modifies what you selected. Press ? for the keys that work right now, or open the command palette and type what you want.

j k move x complete u undo Ctrl+P every command

Quick Add

Catch the thought. Keep your place.

Quick Add puts a task in the Inbox without leaving where you are. Type "tomorrow", "next fri" or "in 3 days" and it becomes a date; type / and a project name to file it there.

q quick add

{{ site::shot(src="landing/quick-add.webp", class="shot reveal grow", alt="Animation: Quick Add opens at the bottom of the screen, Call the plumber tomorrow is typed, it previews the start date, and Enter adds the task") }}

Notes, checklists, comments

Details, out of the way.

Any task, project or area can carry a Markdown note and dated comments, and a task its own checklist. In the list they are a quiet icon and a 1/5; one key opens them in a panel at the side.

\ open the panel c quick comment

{{ site::shot(src="landing/attachments.png", class="shot reveal grow", alt="The attachments panel at the right of a project, showing a task's Markdown note, its five-item checklist with one item checked, and a dated comment") }}

Find anything

Everything is close.

The Navigator jumps to any view, area or project. Go to Symbol finds any task by name, and search reads every title, description, note, comment and checklist item as you type.

Ctrl+K Navigator / go to symbol Ctrl+F search

{{ site::shot(src="landing/search.png", class="shot reveal grow", alt="Search results for review: three tasks with the word highlighted in a title and a description, each with the project and section it lives in") }}

Panes

Two places at once.

Open a project next to Today, or as many panes as fit. Each has its own history, and an edit in one shows in all of them at once.

Ctrl+W v new pane Tab next pane

{{ site::shot(src="landing/panes.png", class="shot reveal grow", alt="Two panes beside the sidebar: the billing project on the left and Today on the right") }}

Make it yours

Twenty themes. A little weather.

Keep Terminal Dark, which takes its colors from your terminal, or pick one of nineteen more, dark and light, with a live preview. Gentle animations show where things land, and if you step away for half an hour the season's weather drifts across the screen.

Anywhere

Wherever there's a terminal.

  • SSH and tmuxRuns on a server as well as on your laptop, and copies over SSH.
  • macOS and LinuxAny modern terminal, from 80 by 24 up. The kitty keyboard protocol is used when there is one.
  • Saves as you goEvery change is written to the file, with 30 daily backups and a recovery file if anything crashes.
  • Edit it anywhereChange the file in another editor and the app picks it up, or asks which side to keep.
  • Mouse welcomeClick rows, checkboxes and the sidebar, scroll with the wheel. Nothing needs it.
  • No accountNo sign-in, no cloud, no telemetry. Just a file.
