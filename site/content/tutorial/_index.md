This tutorial takes ten to fifteen minutes. It starts with why textual-items++ keeps your tasks in one plain-text TaskPaper file, and why areas, projects and an Inbox keep a list calm. Then it puts you at the keyboard: you open a sample file and learn the app one chapter at a time, from moving around to dates, notes and split panes.

Each chapter builds on the one before, so read them in order the first time. Every chapter says which keys to press and what you should see. It doesn't try to cover everything; the [Reference](@/reference/_index.md) has the rest.

You need `tipp` installed:

```sh
cargo install --git https://github.com/sazonovkirill/textual-items-plus-plus
```

Then download the sample file, [tutorial.taskpaper](/tutorial/tutorial.taskpaper), and put it somewhere you can find it. It holds a few weeks of one person's life: an Inbox of loose ends, a Work area with a newsletter to launch, and a Home area with a weekend trip to plan. Open it with:

```sh
tipp tutorial.taskpaper
```

Every chapter carries on in the same file. Each screenshot starts from a fresh copy of it, so your screen may show a task or two you added in an earlier chapter. If you want a clean start at any point, download the file again.
