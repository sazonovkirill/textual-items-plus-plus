The order the app is built in, written once the functional requirements are accepted. Each milestone is one Todoist task in the project `textual-items++`, made of small steps that each leave a working, validated app ([agent workflow](../docs/agent-workflow.md)).

None yet. Each milestone lists its steps, the requirement IDs it delivers, and what the owner checks to accept it. When every step is on `main`, work stops for the [milestone review](../docs/agent-workflow.md#milestone-review) and the owner's acceptance.
